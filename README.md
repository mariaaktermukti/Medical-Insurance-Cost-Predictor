
# Medical Insurance Cost Predictor

This application predicts medical insurance costs based on personal information using a Random Forest machine learning model.

## Features
- Predicts insurance costs based on:
  - Age
  - Sex
  - BMI
  - Number of children
  - Smoker status
  - Region

## Model
Trained using Random Forest algorithm on medical insurance dataset.
